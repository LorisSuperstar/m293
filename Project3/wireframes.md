# Wireframes — Webshop (Mobile / Tablet / Desktop)

## Mobile (320–480px)
- Header: Logo / Hamburger menu / Warenkorb-Icon
- Hero: 1 Spalte, Featured Slider (1 Produkt sichtbar)
- Kategorien: horizontales Scroll-List (Chips)
- Produktliste: 1 Spalte Grid, Karte: Bild, Titel, Preis, "In den Warenkorb"
- Produktdetail: Bild oben, Video unter dem Bild, Titel, Preis, Beschreibung, Bestellformular
- Footer: Kontakt / Impressum

## Tablet (600–900px)
- Header: Logo, Navigation (kompakt), Warenkorb-Icon
- Hero: 2 Spalten Grid für Featured Produkte
- Kategorien: Mehrere Chips in Zeile
- Produktliste: 2 Spalten Grid
- Produktdetail: Bild/Video links, Meta (Preis, Bestellformular) rechts

## Desktop (≥900px)
- Header: volle Navigation, Warenkorb-Anzeige
- Hero: 4 Spalten Grid für Featured
- Produktliste: 4 Spalten Grid (auto-fill minmax 200px)
- Produktdetail: große Medienvorschau links, Details rechts

(Anmerkung: Wireframes sind als textuelle Beschreibung vorhanden. Optional: PNG/SVG-Skizzen können ergänzt werden.)
