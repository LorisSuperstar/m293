# Dokumentation des KI-Einsatzes

Projekt: Webshop mit KI-gestützter Webentwicklung

Verwendete Tools
- GitHub Copilot: direkt in VS Code zur Code-Vervollständigung, Boilerplate und kleinere Templates (HTML/CSS)
- ChatGPT (Konversation mit CLI-Agent): zur Planung, Regex/Glob-Befehlen, Hilfestellung beim Umwandeln von JS in statisches HTML und Erstellen von Dokumentationstexten

Kriterienvergleich (selbst definiert)
1. Integration
   - Copilot: Nahtlos in VS Code, Vorschläge inline
   - ChatGPT: Separate Konversation, sehr gut für konzeptionelle Fragen
2. Vorschlagsqualität
   - Copilot: Schnelle Boilerplate, guter Kontext für lokale Codevorschläge
   - ChatGPT: Ausführlichere Erklärungen, bessere Schritt-für-Schritt-Anleitungen
3. Geschwindigkeit
   - Copilot: Sehr schnell beim Tippfluss
   - ChatGPT: Interaktiv, benötigt Prompting
4. Erklärbarkeit
   - Copilot: Weniger erklärend, mehr Autocomplete
   - ChatGPT: Besser für Dokumentation und rationale Entscheidungen

Beispiele für effektiven Einsatz
- Layout: Copilot hat Grid-Templates und CSS-Klassen vorgeschlagen
- Problemlösung: ChatGPT half bei der Entscheidung, welche Features statisch zu rendern und welche minimal per JS zu belassen

Ethik & Kontrolle
- Alle generierten Texte und Code wurden geprüft und gegebenenfalls angepasst. Keine fremden Lizenz-geschützten Assets wurden eingefügt.

Fazit
- Kombination beider Tools beschleunigt Entwicklung: Copilot für schnellen Code, ChatGPT für Architektur und Dokumentation.
